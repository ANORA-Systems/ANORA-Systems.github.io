2. Subject Matter and Plans

(1) With SpecScout, the Provider offers software for the automated identification, research, extraction and structuring of technical product data (Software-as-a-Service).

(2) The data is obtained from publicly available sources using automated methods, including AI models.

(3) SpecScout only outputs a value if at least two independent sources agree or an authoritative source, in particular the manufacturer, confirms it. Pages about a model other than the one searched for are filtered out. If a value is not confirmed in this way, it is returned as “not_found” instead of being estimated. Each value output is shown with links to its sources and a confidence score; the confidence score is an automated assessment of the sources and not an assurance. This service description defines the agreed quality of the data. Beyond it, the Provider does not owe that the data is correct, complete and up to date, in particular not where agreeing sources are themselves incorrect.
