How we measured

The products
{{ results.products_total }} current products from {{ results.categories_total }} categories, buyable in Germany, from smartphones to sleeping bags and cars. Per category one product with a clear spec table from the manufacturer, two average ones and one whose specs are mainly in PDF datasheets, marketing copy or at retailers.
The expected values
For every requested spec, an AI model drafted a value with a quote and the page it came from. Two people on our team accepted, corrected or rejected each draft by hand, using the manufacturer's pages first. Where SpecScout and the expected value disagreed, we checked the web again and corrected wrong expected values.
The search
The SpecScout version of {{ results.date }}, unchanged, one request per product against the live web, as our customers use it.
What counts as correct
A value is correct if it matches an expected value after converting units, within the tolerance set for the spec. An answer includes the right value if at least one of its values is correct, and it matches exactly if its values and the expected ones are the same, every value of a list included.

What the numbers mean

  • Right value included: answers with at least one correct value, out of all answers to specs whose value is published ({{ results.included_count }} of {{ results.answered }}). Values returned where none is published are counted on their own ("A value anyway", {{ results.fabricated }}).
  • Exact match: answers whose values are exactly the expected ones, out of the same answers ({{ results.correct }} of {{ results.answered }}).
  • Completely wrong: answers without a single correct value, out of the same answers ({{ results.no_correct }} of {{ results.answered }}).
  • Published specs answered: answers out of all specs whose value is published somewhere ({{ results.answered }} of {{ results.documented }}).
  • Confidence: for a list, the lowest confidence score among its values.
